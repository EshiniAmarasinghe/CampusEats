# CampusEats Dashboard (SE3090 Lab 02)

React + Vite single-page app for browsing the CampusEats menu, searching dishes, viewing a dish and
placing a validated order. See `../LAB_NOTES.md` for task explanations and Quick Test answers.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
npm run lint
```
